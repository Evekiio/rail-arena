# Rail Arena v0.1.0-pre-alpha.1

The first downloadable pre-alpha of **Rail Arena**, a focused FPS / aim-training portfolio project by **Sanders Riddle**, built with modern AI agentic workflows and human design review.

## Download and play

Download `RailArena-v0.1.0-pre-alpha.1-Windows-x64.zip`, extract the entire archive, then run `RailArena.exe`. Keep all adjacent files together. No Unity installation or online account is needed for offline play.

**WASD** move · **mouse** aim · **left click** fire · **hold right mouse** 1.5x zoom · **hold Space** hop · **Tab** scoreboard · **Escape** pause/settings.

Start with solo practice, then try three combat bots. Use the same release on both machines for a direct-IP duel.

## In this checkpoint

- Approved original 1m precision carbine, ivory/graphite/cyan materials, three LODs and 2K surface maps.
- Four stylized contender appearances, character-matched forearms, fitted wrist/shoulder contacts and trigger/recovery presentation.
- Instant-hit click-only rifle, unlimited energy, no reload and 0.6-second recovery.
- Existing playable Foundry arena, momentum movement, practice scenarios, health pickups, jump pads, respawns, results/rematches and direct-IP duel integration.
- Editable source, Blender masters, coordinated references, reproducible headless tooling and comparison galleries in the repository.

## Pre-alpha limits

This is unfinished and intended for feedback. Current damage remains **head 100 / body 50 / limb 34**, and timed matches remain ten minutes. The approved new map, portal pair, regeneration, five-minute/20-kill rules and broader settings remain separate implementation work. Reference artwork does not establish that those features are installed.

Human review of visual intersections, animation, physical-input feel and sound remains open. Automated duel checks cover local loopback peers; real internet multiplayer acceptance is not complete. **1080p/144fps is a target, not a certified result.**

Validation, build identity and archive checksum are recorded in the repository's pre-alpha evidence. The archive also contains a per-file SHA-256 manifest. Use `SHA256SUMS.txt` to verify the download.
