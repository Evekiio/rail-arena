# Rail Arena v1 alpha

The current development baseline is v1.0.0-alpha.1. Continue polishing and updating v1 alpha until Sanders, the approving game developer and designer, explicitly approves progression beyond this phase. Publication of an alpha checkpoint is not final design approval.

The Windows review package is based on CombinedGraphicsReview v12. It includes Sky Gardens, Physics Lab (G), movement/crouch/sprint shot spread with an accurate reticle boundary, double-tap Shift slide, rifle/reloading/ADS, portals and jump pads, updated lighting and textures, and the experimental atmosphere, rifle and waterfall candidates. The distracting experimental cyan GPU burst is removed.

Recorded validation: 39 standalone mechanics checks passed with zero logged errors; targeted movement-spread, HUD, networking and hit-detection checks passed. Human input, sound, graphical acceptance, real-internet multiplayer and performance acceptance remain open.
