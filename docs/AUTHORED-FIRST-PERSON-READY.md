# Authored first-person ready

The Sky Gardens art profile now substitutes an original Blender-authored rifle raise for the earlier procedural raise. It lasts 0.3 seconds, with a controlled acquisition and slight settle before the exact calibrated rest pose. The legacy path remains unchanged without the art profile. Movement, camera/input direction, physical ADS endpoint/1.5× zoom, recoil, damage, accuracy, magazine timing and firing availability remain authoritative in their existing code.

The editable source is `Animation/FirstPersonReady/Carbine-FirstPerson-Ready-v1.blend`, derived from the original measured rifle master without changing it. An explicit quaternion basis converts Blender `(x,y,z)` into rifle Unity `(-y,z,x)` in metres. Nineteen evaluated 60 Hz pose samples drive the runtime track; no alternate formula attempts to approximate the source curves. The technical package has six equal-scale views at six times, a 1.6 m view span, a ruler, assembly bounds and one measured sheet. These are weapon-only construction references; the existing compatible arm rig follows the calibrated weapon grips in Unity.

`FirstPersonEquipArtBuilder.Prepare` verifies source/master hashes, duration, sample count, finite transforms, normalized quaternions, a 0.2 m/15 degree envelope and the exact rest endpoint. It updates a stable ScriptableObject identity. `ArtSlicePresentation` installs and restores the previous session track. The motion class keeps its existing landing, stride, sway and recoil paths. `Reset(false)` clears the ready pose; the existing death/pause/reduced-motion logic already uses that path. Physical ADS suppresses this root offset/rotation as before, preserving full sight alignment. No new network field or gameplay callback is introduced.

The final native player-eye review passes 720 before/after samples across four arm appearances and hip, ADS and ADS-entry cases. All 400 full-ADS samples preserve a centred sight axis and 0.38 m eye relief. Maximum recorded wrist error is 0.003 mm; actor root, velocity, capsule, simulation tick, ammunition and next-shot timing remain fixed. Reset and removal of the art profile are checked. Three existing legacy motion regressions pass. Numeric CSV precision is one micrometre and does not certify every palm/finger surface or all camera-clearance configurations.

The six-second comparison runs at 1280×720 per side, 60 Hz, silent. Camera/FOV/appearance/frame samples match; background atmospheric time is not identical. Main-camera captures exclude the HUD and illuminated overlay reticle. The original fixture failure (inactive view weapon) and provisional aerial-camera numerical pass remain recorded separately. The final player-eye review supersedes them for visual evidence.
