# Measured garden nature production

The source package adds eleven original Blender modules for the four existing Sky Gardens planting sites: a trunk, three crown variants, two shrub variants, two grass variants, a vine-stem assembly and two vine-leaf variants. Thirty-three reducing LOD exports use one original opaque painted palette material per mesh. No external or paid dependency is introduced.

## Authority and geometry

`GardenNatureArtBuilder.Audit` reads the installed Sky Gardens Basement scene without saving it. `nature-source.json` records twenty-four renderings, mesh GUIDs, vertex/index hashes, world-space metre bounds and source wind/collider roles. All twenty-four are noncolliding. The four pairs of ivy stems/leaves share their original union frame so independently authored leaves do not drift from their stems. Original physics, navigation and device placement remain authoritative. Paired vine stems join leaves in decorative wind using the same centre, scale, phase and time step; their native rotations are checked together.

`ArtSource/Original/ArtPass-v1/Nature/GardenNature/Garden-Nature-v2.blend` is the canonical metre-scaled unit-frame master. Editable components remain in named family/LOD collections. CrownA LOD0 is initially visible; other collections are available separately. Blender coordinates convert to Unity as `(x,z,-y)`; native axis conversion and every imported vertex remain to be checked before installation.

Each module has a one-metre reference frame. Its actual geometry dimensions are recorded separately, and original installation frames give the precise world-space scale. All three LODs use a common frame rather than stretching each simplified mesh to refill its bounds. Ivy's shared stem/leaf frame stays fixed across both families. There are no rig, clip, grip or root-motion dependencies. Decorative wind follows the existing motion curves; paired vine stems and leaves move together. Original hidden motion components are disabled and restored on cleanup.

The master contains original tapered tube branches, faceted crowns, folded opaque foliage and a packed painted palette. The 384x384 atlas has nine inset swatches, original gradients, leaf veins and bark strokes. It is not an alpha-card foliage system. Source models do not establish runtime draw-call savings or frame-time acceptance.

## Reference package and reproduction

The package contains sixty-six equal-scale geometry-derived orthographic images, eleven measured sheets, perspective/detail views and four audited installation-scale diagrams. Sheets include metre rulers, actual geometry dimensions, LOD budgets, installation-frame dimensions, source identity and a 1.8 m / 0.72 m controller comparator at the same pixels/metre. Detail crops use their separately labelled 0.6 m span. Installation diagrams use source frame transforms plus temporary planter/controller context; they are not Unity screenshots or new production meshes.

Run hidden Unity `GardenNatureArtBuilder.Audit`, hidden Blender `tools/build_garden_nature_art.py`, then `tools/align_garden_trunk_art.py` and `tools/render_garden_nature_refs.py`. Bundled Pillow Python `tools/package_garden_nature_refs.py` composes sheets and resolves the audited per-site module bindings. Hidden Blender `tools/render_garden_nature_sites.py` produces actual-scale diagrams, then rerun the package composer to link them. Reference scripts check the master hash and never save it. Native `GardenNatureArtBuilder.Prepare` creates stable canonical mesh assets, eleven prefabs and the twenty-four-entry installation set. `GardenNatureArtReview` performs the scoped installation/cleanup checks and records native comparisons plus wind playback. The complete art builder prepares the family automatically.

## Native import and installation

Unity FBX conversion reflects X relative to the declared Blender `(x,z,-y)` reference. The initial rotation-only normalization failed with a 0.256619 m unit-frame deviation. Read-only native diagnostics recorded zero root/mesh rotations and the mirrored bounds. Preparation now bakes the reflected positions and inverse-transposed normals into owned canonical mesh assets, flips tangent handedness and reverses triangle winding. The original FBX source is untouched and prefab scales stay positive. Every canonical vertex cloud is checked in both directions against the master at 20 micrometres; all thirty-three imports currently match at zero positional deviation. Native face checks also verify outward winding against imported normals.

`ArtSlicePresentation` replaces the twenty-four exact source renderings inside their audited installation frames and records their original renderer/motion flags. New renderings add no collision. Cleanup restores source meshes, flags and decorative motion; the other existing art modules keep their established ownership path. The build-scene hook still installs the art profile only in Sky Gardens Basement, preserving older maps.

The first native cleanup test incorrectly compared animated actor hitbox poses across removal of the entire existing character-art controller. The corrected fixture preserves all collider identities and serialized definitions, verifies invariant world/controller placement and mesh data, and checks every collider transform during nature-only visibility toggles. It does not redefine expected character animation as a nature collision regression. Native captures remain controlled Editor views, with overlay HUD/native input/audio excluded.

## Scope and remaining acceptance

The first source milestone is preserved in commit `319a6f113d1627d51baa4bfc54124044ac428fb2`. Its flat shrub masses and bare branch tips were refined into cupped leaf rosettes and a scaffold aligned to actual crown interiors. Grass direction/width compensates for the wide, shallow installation frames, preventing flat ribbon-like blades. Vines use varied strand lengths, cupped silhouettes and matched stem/leaf anchors along each actual LOD stem path.
