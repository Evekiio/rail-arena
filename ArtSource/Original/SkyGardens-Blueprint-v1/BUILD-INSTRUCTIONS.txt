SKY GARDENS / MEASURED CONSTRUCTION v1

STATUS: PROPOSED DESIGN, PENDING CREATOR APPROVAL.
No gameplay map was replaced and no new local player build was made in this blueprint step.

AUTHORITY
Scene.json contains the named construction objects, dimensions and placement envelopes.
MeshData.json is the canonical triangulated mesh representation generated by Blender.
All 14 SVG sheets and PNG previews derive from Scene.json using tools/build_sky_blueprints.py.
The AI concept sheets remain mood references. They are not geometry authority.

AXES / UNITS
Metres throughout. Canonical and Blender: X east, Y north, Z up.
Unity: (canonical X, canonical Z, -canonical Y).
UnityConstructionBuilder reverses triangle winding for Unity's front-face convention.
Structural import tolerance: 0.001 m. No unexplained scale factors or manual rotations.

DELIVERABLES
Six orthographic external views: Top, Bottom, Front-South, Back-North, Left-West, Right-East.
Five isolated layers: Lower +0m, Wings +2m, Crown +4m, Summit +22m, Environment.
Three true section cuts: east/west at n=0, north/south at x=0, ramp profile at n=8.
Placement.csv: named object dimensions and collision classification.
Scene.json: ramp profiles, reserved landings, spawn/pickup/portal positions and foliage envelopes.
SkyGardens-Construction.blend: editable, named, grouped metric construction master.
FBX / GLB exports: portable construction geometry. FBX native Unity import is an alternative,
but only the direct manifest-based Unity construction route was bounds-verified here.

BLENDER
Open SkyGardens-Construction.blend. Collections separate structure, ramps, cover, summit,
devices, landing reservations and environmental envelopes. Envelope objects are wire display.
To reproduce: background Blender runs tools/build_sky_construction.py from the repository.
The exporter recalculates normals, writes FBX/GLB, and checks GLB reimport bounds.

UNITY (VERIFIED CONSTRUCTION ROUTE)
Copy the CONTENTS of UnityReadyAssets into a Unity project's Assets folder, keeping all
.asset/.meta/.unity files together. Open Assets/Validation/SkyGardensConstruction/
SkyGardensConstruction.unity. This is a construction scene, not a playable ArenaSession.
It uses a neutral default material and intentionally has no gameplay camera or scripts.
Only parts marked collision in Scene.json have MeshColliders. Portal housing/aperture,
planting, waterfall and landing envelopes are reservation geometry, not final colliders.
Alternatively put UnityConstructionBuilder.cs in an Editor folder and invoke its Build method
headlessly with --sky-blueprint-root pointing at this directory. The output folder must not
already exist. It builds Assets/Validation/SkyGardensConstruction and preserves build settings.

DECISIONS ESTABLISHED FOR REVIEW
Base: Foundry v2 56 x 40 m; wings +2 m; Crown +4 m.
New summit: top +22 m, underside +21.4 m, diameter 14 m, four columns top +27 m.
Four pads retain Foundry start positions and now lead to four 3 x 3 m summit landings.
Gravity 25 m/s2; nominal flight 2 s; initial vertical speed 36 m/s; apex 25.92 m.
Existing wing access remains via ramps. Summit return is a deliberate open-edge drop,
requiring physical acceptance; no added fall damage is proposed.
Outboard decorative gardens expand the visual width to 62 m, without adding playable lanes.
Cloud datum -24 m; waterfall envelopes descend from h=0 to -20 m.

ACCURACY LIMITS / NEXT DESIGN GATE
This package reproduces the measured construction and reservations, NOT every ornate detail
in the AI concept. Leaf clusters, vines, arch ornament, roof/canopy beams, stone damage,
waterfall surface shape, materials and VFX need separate asset design before detailed modeling.
Portal envelopes are not solid collision construction. Current live destination views and
weapon/movement behavior remain requirements for the future playable integration.
Game balance, controller landing/return paths, spawn safety, navigation, foliage sightlines,
waterfall/audio comfort and hardware performance have not been validated by these mesh checks.
