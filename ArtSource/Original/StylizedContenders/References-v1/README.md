# Character reference package v1

Use [the offline viewer](Final/index.html) and [modeling guide](Final/MODELING-GUIDE.md). `Final` contains the sixteen selected reference sheets, the original approved concept, prompts and a file manifest.

Images elsewhere in this directory are generation inputs, intermediate corrections or rejected attempts. They are retained for traceability and are not alternate canonical designs. In particular, do not use `Axial-Rejected-Perspective.png` as an orthographic construction reference.
