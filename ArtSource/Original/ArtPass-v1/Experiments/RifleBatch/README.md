# Rifle batching experiment / archive reference

This is an unpromoted rendering experiment, not installed production artwork or code. Review 20 remains the verified player. The candidate reduced submitted draw calls by only 1.1–3.8%; wall means were worse in all five controlled views. Native buffer, matched visual, reload and candidate gameplay checks pass, but a frame-time improvement was not established.

Editable prototype runtime/test sources are retained as noncompiled `.cs.txt`, with the integration patch and recorded original Unity identities. Scripts reproduce the on/off profile against the historical candidate executable; the normal production player does not implement the experimental flag. Original build-source commit: `ece7ae6989376cdac8e80408618d4ef4f0630af5`. Source/master rifle geometry is unchanged.

See `docs/RIFLE-RENDER-BUDGET.md`, `Validation/rifle-batch-candidate-21.json` and the recorded controlled comparison. Do not promote the prototype without new evidence that addresses the failed performance outcome. No final artistic/native acceptance or public prerelease is implied.
